# Site « Open Badges IMT-BS »

Créé le 02/11/2026. Site statique HTML/CSS (sans JavaScript) qui explique l'usage des badges IMT-BS, pour les étudiant·es et pour les porteurs et référent·es.

- `index.html` : contenu (comprendre, catalogue des 6 badges avec statut, obtention et LinkedIn, circuit de validation et rôles, repères, questions fréquentes).
- `style.css` : charte IMT-BS (violet #AD1D89, bleu #00B8DE, noir, blanc ; Helvetica Neue / Arial).
- `img/logo-imtbs.png` : logo IMT-BS réduit.

Sources : `../Badges_IMT-BS.md`, `../2026-10-05_Point_Etape_Badges.md`, `../CR_Operation_Badges_IMT_BS_20260930.pdf`, `../AmbassadeursIMTBS/CR_Badge_ambassadeur_20261012.pdf`, présentation CFP du 21/05/2026.

À mettre à jour quand un statut change (pastille `statut valide|cours|cadrage|envisage|reporte` sur la carte, tableau des rôles, frise des repères). Pas encore en ligne : hébergeable tel quel (Cloudflare Pages, page Moodle…).
